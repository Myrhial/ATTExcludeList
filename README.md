# AllTheThings Exclude List
See something on ATT you'd rather hide? For a while or for good? Now you can do that.

## Commands

Use item links in the following commands:

Support for other ATT object types is planned for a future release.

- `/attex add <item link>`: Add an item to the exclude list and hide it in ATT.
- `/attex remove <item link>`: Remove an item from the exclude list and show it in ATT.
- `/attex print`: Print all excluded item IDs.
