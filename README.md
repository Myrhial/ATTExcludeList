# AllTheThings Exclude List
See something on ATT you'd rather hide? For a while or for good? Now you can do that.

## Commands

Use thing links in the following commands:

- `/attex add <thing link>`: Add a thing to the exclude list and hide it in ATT.
- `/attex remove <thing link>`: Remove a thing from the exclude list and show it in ATT.
- `/attex print`: Print all excluded things by kind and ID.
